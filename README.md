# 謝沛璇 — 個人作品集

平面設計作品集，使用 HTML、CSS 與 JavaScript 建立，無須建置工具。

## 本機瀏覽

以瀏覽器開啟 `index.html`。Google Fonts 字型需要網路連線。

## GitHub Pages

在倉庫 Settings → Pages 將來源設定為 Deploy from a branch，選擇 main / (root)。

## 編輯

- `index.html`：網站內容及履歷。
- `styles.css`：視覺與響應式排版。
- `script.js`：桌面視窗、動畫及作品說明。
- `assets/`：頭像、履歷下載與背景素材。

目前三個作品案例為明確標示的版型示範，待替換為實際作品。
